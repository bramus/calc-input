<formula-input>

GitHub npm

A custom input element that accepts mathematical formulas such as 2 + 3 or (2 + 3) * 4. Upon blurring, it displays the calculated result (e.g. 5 or 20); upon re-focusing, it reveals the entered formula again. Under the hood, it maintains three synchronized <input type="text"> fields for effortless form submission.

Features & Component Anatomy

<formula-input> wraps three standard <input type="text"> elements in Light DOM so native HTML <form> submissions and constraint validation work automatically.

🔄 Focus / Blur Switching

Shows the calculated result when blurred and seamlessly switches back to the original formula when focused. Never shows more than one input at a time.

📦 Three Synced Inputs

Automatically renders name, name--formula, and name--result inputs under the hood so form submissions receive both the formula and the result.

⚙️ Configurable Submit & Separator

Choose whether the base name input holds the formula (default) or result via submit="...", and customize the -- separator via separator="...".

🛡️ Safe Expression Parser

Evaluates arithmetic (+, -, *, /, %, ^), nested parentheses, unary operators, and math functions without eval().

🚨 Native Form Validation

Unparsable formulas (like 2 + ) keep showing the formula on blur, display a red invalid border, and call setCustomValidity() to block form submission.

🔒 Clean DOM Attributes

Initial formulas can be passed via the value attribute (e.g. value="2 + 3") without ever writing user-entered values back into the DOM attributes.

Installation & Quick Start

1. Install via npm or Import ESM 
npm install formula-input

Import the package to register the <formula-input> custom element:

import 'formula-input';

Then use <formula-input> anywhere in your HTML or forms:

<formula-input name="size" value="2 + 3"></formula-input>

The 3 Underlying Inputs

Behind the scenes, <formula-input name="size" value="2 + 3"> creates three <input type="text"> elements inside the custom element: 

<formula-input name="size" value="2 + 3">
  <!-- 1. Primary input: always hidden; value controlled by `submit` ("formula" or "result") -->
  <input type="text" name="size" hidden>

  <!-- 2. Formula input: always holds "2 + 3"; visible when focused (or when invalid) -->
  <input type="text" name="size--formula" hidden>

  <!-- 3. Result input: always holds "5"; visible when blurred (and valid) -->
  <input type="text" name="size--result">
</formula-input>

Why Three Inputs?

When a parent <form> is submitted, FormData automatically receives size (either the formula or result depending on submit), size--formula (always the raw formula), and size--result (always the calculated result). At any given time, two of the inputs have the hidden attribute so the user only ever sees one input.

Attributes & Configuration

Attribute Default Description
name "" Base name used to generate the three inner inputs: <name>, <name><separator>formula, and <name><separator>result.
value "" Initial formula string (e.g. value="2 + 3"). Parsed on load so the blurred input shows 5 and focusing shows 2 + 3. User edits update live input properties without writing back to the DOM attribute.
submit "formula" Configures what the primary <input type="text" name="<name>"> contains. Accepts "formula" or "result".
separator "--" Configures the separator between <name> and formula / result. An empty string (separator="") is accepted (producing e.g. sizeformula and sizeresult).
placeholder "" Placeholder text forwarded to the visible inner inputs.
disabled / readonly / required false Standard form control states forwarded to the underlying inputs.

Validation & Direct CSS Styling

When an unparsable formula is entered (such as 2 + or (2 + 3), blurring the field keeps showing the original formula instead of switching to the result input, applies invalid styling (red border), and sets custom validity via setCustomValidity() to prevent form submission. Because <formula-input> uses display: contents and its inner <input> elements inherit box and typography properties (border: inherit, padding: inherit, background: inherit, border-radius: inherit, etc.), any styles applied directly onto <formula-input> automatically apply to the inputs inside it. 

/* Styles applied directly onto formula-input are inherited by its inner inputs */
formula-input {
  border: 1px solid #d1d5db;
  border-radius: 8px;
  padding: 0.625rem 0.75rem;
}

formula-input:focus-within {
  border-color: #2563eb;
}

formula-input:has(input:invalid) {
  border-color: #ef4444;
  background-color: #fef2f2;
}

JavaScript API

const el = document.querySelector('formula-input');

// Read formula, evaluated result, and configured submit value
console.log(el.formula); // "2 + 3"
console.log(el.result);  // "5"
console.log(el.value);   // "2 + 3" (when submit="formula") or "5" (when submit="result")
console.log(el.isValid); // true

// Inspect structured AST & tokens
console.log(el.getEvaluation());

// Check constraint validity
console.log(el.checkValidity());

5. Custom Styling

          

            Because <formula-input> uses display: contents and its inner <input> elements inherit box and typography styles, you can apply CSS properties directly onto <formula-input> and they automatically apply to the inputs inside it.
          


          

            

              Custom Border, Radius & Padding
              Direct Inline Styles
            

            
            
              
<formula-input
  name="custom_border"
  value="12 * 12"
  style="border: 2px solid #3b82f6; border-radius: 9999px; padding: 0.625rem 1.25rem;"
></formula-input>

            
          


          

            

              Custom Background, Color & Monospace Font
              Direct Inline Styles
            

            
            
              
<formula-input
  name="custom_colors"
  value="(1024 / 16) * 8"
  style="background-color: #0f172a; color: #4ade80; border: 1px solid #22c55e; border-radius: 4px; font-family: monospace;"
></formula-input>

            
          


          

            

              Custom Typography, Alignment & Width
              Direct Inline Styles
            

            
            
              
<formula-input
  name="custom_typography"
  value="(250 + 750) * 1.21"
  style="font-size: 1.25rem; font-weight: 700; text-align: right; width: 240px; border: 2px solid #059669; border-radius: 2px; font-family: monospace;"
></formula-input>
